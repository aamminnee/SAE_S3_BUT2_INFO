# MyBrickStore

MyBrickStore est une application web permettant de transformer vos photos personnelles en mosaïques de Briques uniques. Téléversez une image, recadrez-la, choisissez la taille de votre tableau et recevez un plan de montage précis ainsi que la liste des briques nécessaires.

##  Accès à la version de démonstration

Le site est accessible en ligne à l'adresse suivante :
 **[https://brickstore.alwaysdata.net/MyBrickStore/Public](https://brickstore.alwaysdata.net/MyBrickStore/Public)**

##  Note technique : Mesure d'audience

Le module de mesure d'audience (type Matomo/Analytics) **n'est pas déployé sur cette version de démonstration**.

**Raison :** L'hébergement gratuit *AlwaysData* impose une limite stricte sur le nombre de fichiers (inodes). Le dossier du module d'analyse contenant environ 12 000 fichiers, il n'a pas pu être transféré sur cet environnement restreint.

 **État :** La fonctionnalité a été implémentée et validée en environnement local. Des captures d'écran et un aperçu des données sont disponibles dans le diaporama de présentation du projet.
